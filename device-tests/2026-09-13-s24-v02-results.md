# S24+ v0.2 앱·사이트 연결 검증

2026-09-13 · Galaxy S24+ SM-S926N · Android16 · 개인 프로필(user0)

- `0.2.0-connectors` APK 설치·실행 성공.
- 설치된 e알리미·하이클래스 감지 성공.
- 클레이모피즘 첫 화면과 자녀 이름·학교·학년 입력 화면 정상 표시.
- ‘연결할 앱과 사이트’ 화면에서 Android 앱과 사이트를 함께 표시.
- 나이스 학교정보 공식 OpenAPI로 테스트 학교 정확 일치 검색 성공.
- 교육청 코드·학교 코드를 암호화된 연결 상태로 저장.
- 향후30일 학사일정을 요청하고, 받은 일정 중3건을 연결 카드에 표시.

- 연결 화면의 중복 ‘계속’ 버튼 제거. 앱 스위치 ON→이유 팝업→Samsung 알림 접근→복귀→앱 로그인 안내 흐름 성공.
- 앱 로그인 안내에서 e알리미 실행 성공을 현재 Activity 패키지로 확인. 개인 화면 내용은 읽지 않음.
- e알리미 공식 로그인 페이지를 앱 내 허용 도메인 WebView로 표시. 로그인 전 완료 버튼 비활성, 뒤로 취소 시 스위치 OFF 복원 확인.

## 실측 중 발견·수정한 문제

공식 나이스 OpenAPI가 `Type=json` 요청에서도 `Accept: application/json` 헤더에는 HTTP500을 반환했다. 동일 URL·User-Agent에서 Accept를 `*/*`, `application/json`, `text/html`로 바꿔 PC 비교 요청을 실행했고 각각 200/500/200을 확인했다. 앱을 `Accept: */*`로 수정한 뒤 S24+에서 학교 검색·일정 연결이 성공했다.

이 동작은 제공자 API의 비표준 호환성으로 기록한다. 응답 Content-Type과 JSON 스키마 검증은 유지한다.

## 인증 결정

- 나이스 공개 학교정보는 부모 계정 없이 연결한다.
- 나이스 개인자료용 공개 OAuth/위임 API는 찾지 못했다.
- 약관상 계정의 제3자 사용 방지·종료 시 로그아웃·사전 승인 없는 정보 복제/영리 이용 제한이 있어 부모 비밀번호를 서버에 보관하는 자동 로그인은 구현하지 않았다.
- 앱에는 나이스 개인자료를 ‘공식 연동 준비 중’으로 표시하고 활성화를 막는다.
- e알리미·하이클래스 웹은 공식 로그인 화면과 기기 내 WebView 세션 유지 프로토타입을 제공한다. 로그인 완료는 SESSION_READY, 실제 정보 읽기 성공만 CONNECTED로 구분한다.

## 저장 검증

비개인 테스트 별칭과 학교명을 저장한 상태에서 앱 SharedPreferences와 Room DB 원시 파일을 확인했다. 두 값의 UTF-8 평문이 발견되지 않았고 앱에서는 정상 복호화해 표시했다. 이는 Android Keystore AES-GCM 적용의 기본 증거이며 전문 침투 테스트는 아니다.

## 남은 작업

- 운영용 나이스 OpenAPI 인증키 발급·서버 보관과 호출량/장애 정책.
- 급식·시간표 화면과 주기 동기화.
- 동일 이름 학교 여러 곳의 지역/주소 선택.
- 선택형 위치 권한을 이용한 주변 학교 후보.
- 실제 자녀 정보 입력 후 사용성 검증.
- e알리미·하이클래스 신규 푸시 수집과 원문 무인 연결.
- 웹 로그인 뒤 프로세스 종료·재부팅·장기 만료를 포함한 세션 유지와 개인자료 읽기 어댑터 검증.
- 공식 위임 API/제휴가 없는 개인 사이트를 ‘계정 금고’ 방식으로 우회하지 않기.

실기기에서 사용한 테스트 프로필은 검증 후 앱 데이터에서 삭제하고, 첫 설정 화면으로 돌려놓는다.
