# 나는 엄마다 0.5 제품 검수

현재 버전은 가족 실험에서 핵심 가설을 검증할 수 있는 설치형 시험판이다. 설치된 지원 앱을 찾고, 새 알림을 기기 안에 암호화해 모으며, 준비물·제출·마감 후보를 알려주고, 엄마가 확인한 항목을 모모의 부탁으로 저장하는 흐름이 연결됐다.

## 이번에 해결한 핵심 문제

- 홈에서 가장 중요한 행동이 먼저 보이지 않던 문제를 Agent Hero + Bento 구조로 수정했다.
- 알림 후보를 다시 입력해야 하던 동선을 `모모가 챙기기` 한 번으로 줄였다.
- 후보와 부탁을 중복 집계하지 않으며 같은 알림으로 부탁을 두 번 만들지 않는다.
- 중요한 후보 알림은 별도 스위치와 Android 알림 허용을 모두 거쳐야 발송한다.
- 설치 앱 두 개 제한, 미설치 추천 잘림, 초등 학교·학년 강제 입력을 완화했다.
- 웹 인증을 자동으로 확인한 것처럼 표시하지 않고 사용자 확인 상태와 자동 조회 지원 여부를 분리했다.
- 웹 로그인 화면 캡처, 전체 삭제 단락평가, 나이스 일정 누락과 학교변경 경합을 수정했다.

## 제품 성공을 위해 다음으로 필요한 기능

1. **기한 확인 화면**: `내일`, `9월16일`을 공지 게시 시각 기준의 날짜로 보여주고 엄마가 알림 시각을 확인한 뒤 저장하도록 한다.
2. **공식 개인 공지 커넥터**: e알리미·하이클래스 등 공급자와 정식 API·약관을 합의해 로그인 성공, 세션 만료, 새 공지 조회를 공급자별로 구현한다.
3. **연결 건강 상태**: 홈에는 정상 연결 수보다 `다시 로그인`, `알림 접근 꺼짐`, `최근 수신 없음`처럼 조치가 필요한 상태만 보여준다.
4. **학교 검색 후보**: 위치 권한을 먼저 요구하기보다 입력한 지역·학교명으로 나이스 후보를 보여주고, 필요할 때만 주변 학교 검색을 제안한다.
5. **실사용 오탐 평가**: 실제 엄마5~10명이7~14일 사용하며 원문 공지와 후보를 대조해 정보 확보율·오탐·놓친 중요 공지를 측정한다.
6. **다자녀와 공동 보호자**: 실제 인터뷰에서 필요율과 개인정보 경계를 확인한 뒤 자녀별 소스·일정·공유 범위를 설계한다.
7. **구매 지원**: 준비물 확정과 상품명 정규화가 안정된 후 선호 쇼핑몰 링크 비교를 추가한다. 결제 전에는 항상 엄마의 최종 확인을 둔다.

## 배포 전 남은 조건

- 현재 release APK는 가족 시험을 위한 개발 서명이다. 일반 배포 전 Google Play App Signing과 전용 업로드 키가 필요하다.
- 개인 웹 공지 자동 조회와 로그인 자동 갱신은 공식 커넥터가 없어 지원하지 않는다. 쿠키 존재는 로그인 성공의 증명이 아니다.
- Android13~15, Samsung 외 제조사, 재부팅·Doze·장기 세션, 실제 학교 앱의 신규 알림 확보율을 추가 검증해야 한다.
- 자녀 공지를 다루므로 운영 전 개인정보 고지, 이용약관, 문의·삭제 대응 절차를 법률 검토해야 한다.

## 출시 판단

가족 실험: 진행 가능. 제한된 사용자 테스트: 위 미지원 범위를 명시하고 진행 가능. 일반 공개 출시: 공식 개인 공지 커넥터, 실제 사용자 데이터 검증, 운영 서명과 개인정보 운영 절차를 마친 뒤 진행한다.
