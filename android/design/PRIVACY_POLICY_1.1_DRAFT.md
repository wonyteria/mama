## 1. 수집하는 정보

- **알림 콘텐츠**: 사용자가 알림 접근 권한에서 허용하고 앱 내 수집 대상으로 지정한 앱의 알림만 수집한다. 알림 extras의 텍스트 필드(`EXTRA_TITLE`·`EXTRA_TEXT`·`EXTRA_BIG_TEXT`·`EXTRA_TEXT_LINES`)와 발신 패키지명·게시 시각 같은 알림 메타데이터를 저장한다. **알림에 첨부된 이미지나 파일은 읽거나 OCR·텍스트 추출하지 않는다.** 수집 대상 외 앱의 알림은 읽지 않는다.
- **자녀 정보**: 사용자가 직접 입력한 자녀 별칭·학교명·학년·학교급(초/중/고)을 저장한다.
- **연결 소스 정보**: 사용자가 연결한 학교 웹사이트 URL과 연결 상태 메타데이터(최근 조회 성공 시각·능력·미지원 사유 등)를 앱 저장소에 저장한다. e알리미/하이클래스 같은 제3자 사이트의 WebView 로그인 세션(쿠키·WebStorage)은 앱 데이터가 아니라 기기의 OS WebView 저장소에 남는다.
- **학교 웹사이트 첨부 문서**: 연결된 학교 웹사이트 공지에 첨부된 HWP·HWPX 문서를 내려받아 본문 텍스트를 추출한다. 이미지나 그 외 바이너리는 OCR하지 않는다.
- **읽음/조치 상태**: 수집된 기록의 읽음 여부·생성된 할 일의 완료/미루기 상태를 저장한다.

## 2. 정보의 이용 목적

- 수집된 알림에서 학교 공지·준비물·행사 정보를 추출해 할 일(부탁)과 아침 브리핑을 생성한다.
- 사용자가 지정한 로컬 캘린더에 학교 일정을 등록·갱신한다.
- 사용자가 정한 시각에 알림을 울리기 위해 알람을 예약한다.
- 알림 텍스트와 자녀 정보의 처리·판정은 기기에서만 수행한다.

## 3. 저장·암호화·보관 기간

- 알림 텍스트·자녀 정보는 기기 내 로컬 데이터베이스에 **암호화되어** 저장된다(`encryptedPayload`).
- 수집 기록은 **수신 후 14일**이 지나면 자동 삭제 대상이 된다(`RETENTION_MS`). 삭제는 백그라운드 정리 작업과 앱 실행 시 수행된다.
- 사용자는 설정의 "전체 삭제"로 저장된 알림 기록·할 일·연결 상태·온보딩/동의 상태를 초기화할 수 있다.
- 읽음 표시는 별도의 상태(기기 내 읽음 저장소)이며 기록 본문을 바꾸지 않는다.
- 사용자가 기록을 명시적으로 삭제하거나 수집 대상에서 제외해 기록이 폐기되면, 같은 항목이 다시 수집되지 않도록 opaque dedup id와 수신 시각만 담은 tombstone만 남는다 — 제목·본문·첨부 내용은 남지 않는다.
- `android:allowBackup=false` — OS 백업/복원 대상에서 제외했다.

## 4. 외부 전송·제3자 제공

- 수집된 알림 텍스트와 자녀 정보를 **외부 서버로 자동 전송하지 않는다.** 분석·광고 SDK가 없다.
- 앱은 다음 **발신(outbound) 경로**를 사용한다 — 코드상 MAMA 자체 서버·분석·광고 SDK로 보내는 요청은 없다:
  - 사용자가 연결한 학교 공식 웹사이트의 공개 공지 및 HWP·HWPX 첨부 문서 조회(HTTP GET).
  - e알리미·하이클래스 공지 조회 — 사용자가 앱 내 WebView에서 직접 로그인한 세션의 쿠키로 해당 사이트 공지 페이지 DOM을 렌더해 읽는다. 로그인 자격 증명(아이디·비밀번호 등)은 MAMA 서버가 아니라 **사용자가 선택한 공식 제3자 사이트에만 직접 전송**되고, 앱은 자격 증명을 저장·갱신하지 않는다. 세션이 유효한 동안 공지를 읽을 수 있지만, 세션 만료 시 자동 재인증 없이 사용자가 다시 로그인해야 한다. 쿠키·WebStorage는 기기 WebView 저장소에만 남고, 앱의 전체 삭제 실행 시 쿠키 전체·WebStorage가 함께 제거된다.
  - 공개 학사일정 조회 경로는 현재 비활성(`NeisPublicClient.PRODUCTION_SYNC_ENABLED=false`, `NEIS_API_KEY` 미포함) — 활성화 시 공식 NEIS 공개 API를 호출하며 그 경우 본 문서와 Data Safety를 갱신한다.
- 사용자가 설정에서 "내보내기"를 실행하면 JSON/CSV 텍스트가 생성되어 OS 공유 기능으로 전달된다 — 어디로 보낼지는 사용자가 선택한다.

## 5. 알림 접근 권한(Notification Listener)

- 이 기능은 사용자 명시 동의·온보딩 완료·수집 토글·수집 대상 앱 지정·OS 권한 부여가 **모두** 충족될 때만 동작한다.
- 사용자는 언제든 OS 설정에서 알림 접근 권한을 회수하거나, 앱 설정에서 수집을 끄고 저장 데이터를 삭제할 수 있다.

## 6. 사용자 권리

- 열람: Today/기록 화면에서 수집·저장된 내용을 볼 수 있다.
- 삭제: 기록을 명시 삭제하면 본문이 지워지고 재수집 방지용 tombstone(opaque id+수신 시각)만 남는다. 설정의 전체 삭제로 모든 수집 데이터·연결 세션(쿠키·WebStorage 포함)을 제거.
- 수정·동의 철회: 자녀 정보 재설정, 수집 대상 앱 변경, OS 권한 회수.

## 7. 아동 관련

- 본 앱은 보호자가 자녀의 학교 알림을 관리하기 위한 도구로, 아동을 직접 대상으로 하지 않는다. 자녀 정보(별칭·학교·학년)는 보호자가 직접 입력한다.
