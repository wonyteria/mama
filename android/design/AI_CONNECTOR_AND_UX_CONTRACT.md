# 모모 AI·원문 연결·화면 계약

2026-09-15. 개발 전 설계의 세부 계약. 실제 서버, 계정 위임, OCR SDK가 연결됐다는 의미는 아니다.

## 계정과 AI 사용권

| 선택지 | 엄마의 설정 | 비용·한계 | 제품 채택 |
|---|---|---|---|
| 모모 로컬 기본 기능 | 최초 알림 접근 허용 | 호출 요금 없음, 현재는 규칙 처리 | 모든 사용자의 기본·오프라인 기능 |
| 지원 기기 내 생성 AI | 기기 지원 확인·필요 시 모델 다운로드 | 서버 호출료 없음, 기기·언어·배터리·백그라운드 제약 | 장기 보조 경로, S24+ 가능하다고 가정하지 않음 |
| 모모가 제공하는 AI | 처리 범위에 대한 최초 동의 | 엄마에게 무료 제공 가능하나 운영자는 모델·서버 비용 부담 | 상시 자동 비서의 우선 운영안 |
| 개인 Gemini API 무료 구간 | 개발 프로젝트·키 설정 필요 | 모델별 한도, 무상 서비스 개인정보·학습 조건 | 일반 공개·비개인 테스트용. 엄마 기본 가입 단계에 키 입력 금지 |
| 개인 OpenAI API | API 사용권·키 별도 필요 | ChatGPT 무료/유료 계정 보유만으로 범용 API 권한을 보장하지 않음 | 향후 고급 사용자 선택, 기본 경로 아님 |
| ChatGPT 안의 모모 플러그인 | ChatGPT에서 모모 서비스 연결 | 호스트의 이용 범위·정책 적용, 지속 백그라운드 모니터링 보장 없음 | 별도 배포 채널로 검토 |
| ChatGPT/Gemini로 직접 공유 | 사용자가 AI 앱을 열어 공유 | 전환·재입력·결과 반입이 필요 | 비상 수동 보조. 자동 에이전트의 주 경로로 삼지 않음 |

Google 로그인은 신원 인증이다. Gemini 추론 권한·할당량은 프로젝트/API 계약이다. ChatGPT 플러그인 OAuth도 ChatGPT가 모모 서비스에 접근하는 인증이며 모모가 ChatGPT를 무료 호출하는 토큰을 받는 흐름이 아니다.
소비자 AI의 브라우저 쿠키·비밀번호를 수집하거나 웹 UI를 반복 조작해 API처럼 사용하는 구현은 채택하지 않는다. 사용권·기술 계약이 확인되는 기능만 연결됨으로 표시한다.

## 원문에서 행동까지

```text
지원 앱 알림 / 공식 원문 연결
       ↓
수집 상태와 원문 버전 기록
       ↓
PDF 텍스트·이미지 OCR → 표의 행/열·페이지 위치 보존
       ↓
필요한 근거만 추출 → 선택된 AI 처리 경로
       ↓
주장별 근거 대조 → 대상/의무/날짜 역할 검증
       ↓
내일 준비 / 가까운 제출 / 선택 활동 / 대상 외 / 확인 대기
       ↓
자동 정리·브리핑 / 필요한 한 번의 선택 / 허용된 실행
```

커넥터는 `권한 확인`, `공지 목록`, `본문`, `첨부`, `변경 감지`, `인증 갱신`, `연결 철회`의 지원 여부를 각각 보고한다. 하나가 가능하다고 나머지까지 연결됐다고 하지 않는다.
인증 필요 응답·로그인 HTML·차단 페이지는 데이터 0건 성공으로 바꾸지 않는다. 알려진 401/403 외에도 공급자의 데이터 스키마와 인증 결과로 판정한다.
새 공지 ID와 수정 버전, 해시, 마지막 성공 시각, 첨부별 결과를 관리한다. 변경·취소 공지는 이전 행동을 대체하고 중복을 만들지 않는다.
서버가 허용하는 refresh token/세션 갱신만 사용한다. 보안 만료·2차 인증은 우회하지 않고 재로그인 한 건으로 묶어 안내한다. 기존 소식은 유지하고 수집 중단 시점을 표시한다.

## AI가 받는 최소 입력

신원은 기기에 둔다. `아이 이름·반·번호·전화·계정·쿠키·세션 토큰·로그인 URL query`를 기본 모델 입력에 넣지 않는다. 가능하면 AI가 공지의 대상 범위만 추출하고 아이 프로필과의 비교는 기기에서 한다.
원문 전체를 보내는 대신 문단·표의 필요한 행을 보낸다. 그래도 다른 학생 이름·병력·계좌가 남을 수 있으므로 패턴 가림만으로 익명이라고 선언하지 않는다.
개인 공지의 원격 분석은 처리 지역·보관기간·학습 이용·삭제 방식이 검증된 공급자와 최초 동의를 갖춘 경우에만 허용한다. 무료 구간으로 자동 우회하지 않는다.
이미지/PDF는 기본 로컬 추출. 읽기 어려운 부분의 원본 crop 전송은 별도 처리 정책이 허용할 때만 사용한다. 계정 화면 캡처를 원문처럼 서버에 보내지 않는다.
API 키는 서비스 서버의 비밀 저장소에 보관하고 APK·로그에 넣지 않는다. 설치별 인증, 요청 크기 제한, 호출량 제한, 캐시, 취소·삭제 경로가 필요하다.
개인 공지 캐시는 사용자 사이에 공유하지 않는다. 공식 공개 공지만 공개 여부와 최신 버전을 검증해 공유 캐시한다.

## 모델 결과 계약

모델 출력은 실행 명령이 아닌 주장 목록이다. 각 주장에는 `sourceId`, `revisionHash`, `page`, `evidenceSpan`, `field`, `value`, `uncertainty`가 필요하다.
날짜에는 `publication/application_open/application_close/event/result/cancellation` 역할과 연도·월일·시간의 명시 여부를 담는다. 회차 대안은 `exclusiveOptions`로 분리한다.
검증기는 근거 구절의 실제 존재, 숫자·날짜·요일 일치, 접수 순서, 학년 범위, 회차 관계를 확인한다. 모델 스스로 붙인 높은 confidence만으로 통과시키지 않는다.
이번 원문의 ‘선착순 마감’을 ‘추첨’으로 바꾼 결과는 거부한다. 다른 원문에 ‘선착순 아님’이 있다면 반대로 선착순이라고 바꾸지 않는다. 기재하지 않은 비용·차량·준비물을 보충하지 않는다.
원문·첨부·모델 출력에 포함된 시스템 지시, 계정 요구, 임의 URL 실행은 데이터로만 취급한다. 실행기는 미리 정의된 허용 동작과 검증된 원문만 받는다.
실패하면 내부 재추출·재조회·제한된 재시도를 수행한다. 엄마에게 매번 모델 결과를 채점시키지 않는다. 핵심 정보가 빠졌다면 `첨부 확인 대기`로 남긴다.

## 텍스트 와이어프레임

### 홈 / 아침·저녁 브리핑

```text
[모모]                         [설정]
오늘은 이것만 챙기면 돼요
┌ 오늘 준비 ─────────────────────┐
│ 물통 · 오늘 등교 전             │
│ 학교 공지에서 확인     [완료]    │
└───────────────────────────────┘
┌ 가까운 제출 ───────────────────┐
│ 신청서 · 금요일 09:00           │
│ [제출 화면 열기]       [원문]    │
└───────────────────────────────┘
[관심 있을 만한 소식 1개 ▾]
수집 상태: 마지막 성공 시각 / 확인 못한 곳
[모모에게 말하기…]            [보내기]
```

큰 Clay 카드는 필요한 행동에만 사용한다. 요약·수집 상태·원문은 평면 요소로 둔다. 긴 문장은 줄바꿈하고 작은 화면에서 2열을 1열로 바꾼다.
빈 상태는 `확보한 소식에서 챙길 일 없음`, 오류는 `학교 앱 수집 끊김`, 로딩은 `새 소식 정리 중`으로 구분한다. 실제 조사 없이 `모든 것을 챙겼어요`라고 말하지 않는다.

### 선택 활동 상세

```text
[뒤로] 과학 체험 모집
초등 5~6 / 중등 1~3 · 선택 활동
접수 9/28 17:00 → 10/2 09:00
선착순 마감 · 선정 발표 10/7
체험 10/17 또는 10/31 · 오전/오후 선택
[관심 있어요]             [원문]
```

관심을 표시하면 접수·발표 일정을 추적한다. 관심 없는 추천의 마감 알림은 생성하지 않는다. 실제 신청·취소·결제는 결과를 검증할 수 있는 연결이 있어야 한다.

### 모모 대화

```text
[모모]                     [챙길 일]
엄마: 내일 준비물 뭐야?
모모: 물통과 체육복이에요.
      학교 알림에서 확인 [근거]
엄마: 물티슈도 기억해줘
모모: 적어뒀어요.              [취소]
```

명확하고 되돌릴 수 있는 로컬 메모는 실행 후 취소를 제공한다. 비용·개인정보 공유·외부 제출은 실행 전 한 번 확인한다. 모델이 없거나 수집되지 않은 사실은 아는 척하지 않는다.

### 연결 설정

```text
앱 소식       e알리미     [ON] 새 알림 수집
공개 학교정보 나이스      마지막 조회 / sample 범위
개인 원문     e알리미 웹   조회 연동 미지원
첨부 읽기                 아직 사용할 수 없음
AI 처리                   기기 기본 정리
```

AI 모델명·API 키는 엄마의 가입 필수 항목이 아니다. 연결되지 않은 서비스에는 성공 스위치를 제공하지 않는다. 미지원 상태는 고급 상세에 모으되 주요 수집 누락은 홈에서 숨기지 않는다.

## 완료 증거

이 문서와 0.7 구현은 공통 판단·화면·검증 경계의 기반이다. 실제 첨부 OCR 성공, 생성 AI 답변 품질, 개인 웹 자동 조회, 수백 건의 실제 공지 정확도는 각자의 검증 증거가 따로 필요하다. 이를 종합 검증한 뒤에만 ‘모모만 보면 되는 비서’로 출시한다.
