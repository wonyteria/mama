# 나는 엄마다 · 클레이모피즘 디자인 참고

이 HTML은 Kotlin Android 화면 구현을 위한 정적 시각 참고 자료다. 웹 서비스나 동작하는 프로토타입이 아니다.

- 화면 기준: 412 × 892. Android 시스템 상태바·내비게이션 영역은 실제 기기의 WindowInsets를 사용한다. HTML 하단 인디케이터는 참고 장식이다.
- 배경 #F6F4F0 / 본문 #283D36 / 주요 동작 #326D5E / sage #7CBEB0 / peach #F7B7A4 / lavender #CDC4EE.
- 카드 모서리 25~32dp. 빛은 왼쪽 위, 어두운 그림자는 오른쪽 아래. 그림자는 회색보다 옅은 녹색 계열, 넓고 낮은 농도로 사용한다.
- 장식 종은 SVG 참고이며 Android에서는 Canvas 또는 VectorDrawable로 번역할 수 있다. 아이콘·일러스트에는 외부 의존성이 없다.
- 홈은 한 화면에서 수집 상태, 누적 알림 수, 선택 앱 수, 최근 알림을 보여준다. AI 자동 챙김 기능이 아직 없다는 문구를 유지한다.
- 이 참고의 ‘챙길 앱 0’은 설정 전 상태다. 실제 앱에서는 준비 중 카드가 앱 선택 화면으로 이어지는 명확한 ‘챙길 앱 고르기’ CTA를 표시해야 한다. 선택 앱이 있고 권한도 허용되면 ‘수집 준비 중’을 ‘새 알림 대기 중’으로 바꾼다.
- 실제 앱의 ‘전체 보기’, 하단 탭, 준비 카드 CTA는 최소 48dp 터치 영역을 갖는다. 본문은 접근성 글자 크기 확대 시 스크롤할 수 있어야 한다.
- 실제 앱에서 작은 보조문구는 12sp 이상 권장. 디자인 참고에서는 화면 밀도를 보기 위해 일부 메타 라벨을 10~11px로 표현했다.
- 권한 미허용·지원 앱 없음·저장 오류는 이 정적 홈과 별개로 명확한 복구 CTA가 필요하다. 예: ‘알림 읽기 허용하기’, ‘지원 앱 확인하기’, ‘다시 시도’.

## 확인

Chrome headless에서 정적 로컬 HTML을 412 × 892로 렌더링한 reference.png를 참고한다. 통신, 실제 개인정보, 분석 SDK, 외부 폰트는 사용하지 않는다.
