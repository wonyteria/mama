## 변경 범위

- 알라미 공식 스토어 소개 이미지를 참고해 큰 예약 시각, 실제 행동, 고정된 정지·다시 알림 제어를 배치했다. 잠금 중 개인 내용은 숨긴다.
- 명확한 캘린더·알람 생성 문장을 로컬 파서로 해석한다. 모호한 시각·잘못된 날짜·조회·부정 명령은 임의의 저장으로 바꾸지 않는다.
- 쓰기 가능한 선택 캘린더에는 CalendarProvider 저장 후 같은 ID로 확인한다. 외부 시계 앱에는 지원하는 알람 생성 요청만 전달한다.
- 재전송·불명 저장 결과·복원·취소·초기화 경계를 검토했다. 불명 결과는 기존 ID 조회만 하고 새 일정을 자동으로 만들지 않는다.
- 기존 UI·저장소·Android API를 재사용했으며 새로운 의존성을 추가하지 않았다.

## 증거 구분

- GPT-6 Astra High 설계 → GPT-5.5 구현 → GPT-6 Astra High 독립 소스 검토.
- 알람 소스 검토: `REVIEW_0.8_ALARM.md` 마지막 판정. 초기 지적은 후속 수정 판정과 함께 읽는다.
- 캘린더 소스 검토: `REVIEW_0.8_SCHEDULE.md` 마지막 판정.
- PC UI 렌더: 320dp·200% 글씨 및 일반/잠금 화면. 큰 시각·행동·제어의 잘림 수정 후 시각 검토 통과. 실제 알라미 앱과 비교한 우수성 검증은 아니다.
- 과거 개인정보 지적의 현재 소스 재확인: 전체 초기화의 시스템 알림 취소, 공지·부탁 삭제/완료의 해당 알림 취소, 이전 `candidate_feedback` 설정의 재시도 가능한 삭제 마이그레이션을 확인했다.

## 실제 기기 검증 범위

이번 작업의 ADB 장치 목록은 비어 있었다. 0.8 APK를 휴대폰에 설치하거나 실제 사용 계정에 일정을 생성하지 않았다.

자동 테스트의 가짜 CalendarProvider/외부 앱 처리기 및 PC 렌더는 실제 앱 호환성, 클라우드 동기화, AndroidKeyStore 하드웨어, 잠금화면 전환, 절전·재부팅 뒤 알람 도착을 보증하지 않는다. 암호화 codec 테스트의 테스트용 AES/GCM과 실제 AndroidKeyStore 실행을 구별한다.

다음 기기 검증에서는 선택한 실제 캘린더의 저장·읽기·안전한 취소, 시계 앱의 요청 수신, 잠금 상태의 숨김·정지·미루기, 권한 거절·프로세스 종료·다시 시작을 확인한다. 테스트 일정만 사용하고 기존 일정을 삭제하지 않는다.

## 남은 제품 범위

이번 버전은 제한된 명령을 실행하는 로컬 시험판이다. 생성 AI, 이미지/PDF OCR, 개인 웹 공지 자동 수집·인증 갱신, 실제 등하교 서비스 연결, 사진·영상 모으기의 구현 완료를 뜻하지 않는다. 모든 캘린더·리마인더·알라미 앱 연결을 검증한 것도 아니다.

설치파일·소스 경로·해시는 `dist/build-manifest-0.8.0.json`, 사용 범위는 `dist/사용안내-0.8.md`에 기록한다. 로컬 시험용 서명이며 정식 출시 검증은 별도다.
