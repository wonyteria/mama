# Clay design implementation

앱의 디자인 기준은 `reference.png`를 바탕으로 합니다. 구현 화면은 네이티브 Jetpack Compose이며 WebView나 웹사이트 래퍼가 아닙니다.

| 항목 | 구현 |
|---|---|
| 바탕 | 따뜻한 크림 #F6F4F0 |
| 본문 | 짙은 녹색 #283D36, 보조 #60756C |
| 주 버튼 | 진한 세이지 #326D5E, 흰 글자 |
| 카드 | 모서리 28dp, 밝은 윗면·부드러운 12dp 그림자·가는 테두리 |
| 보조 색 | 세이지 #DDEDE2, 살구 #F7D5C6, 라벤더 #E4DFF1 |
| 마스코트 | Compose Canvas로 그린 둥근 종. 외부 이미지 다운로드 없음 |
| 조작 | 주 CTA 최소56dp 높이, 눌림 시 약한 축소, 모든 주요 화면 스크롤 |
| 탐색 | 홈/받은 알림/설정 3개, 떠 있는 둥근 하단바 |

설계 참고의 ‘앱0개인데 수집 준비 중’ 상태는 실제 구현에서 ‘설정 이어하기’와 CTA로 바로잡았습니다. 데이터0건·기기 연결중·수집중·사용자 일시정지는 서로 다르게 표시합니다.

이번 G0의 메뉴와 문구는 AI 일정 관리 완성품을 가장하지 않습니다. 향후 V0에도 같은 컴포넌트를 재사용할 수 있으나, V0 기능은 수집/정확성 검증 뒤에 추가합니다.
