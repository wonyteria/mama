# 나는 엄마다 — 핵심 제품 개선 명세

> 이전 초안 — 구현 기준으로 사용하지 않는다. 최신 결정과 화면·상태·예외·검수 기준은 [최종 제품 설계 V2](DEVIN_PRODUCT_DESIGN_V2.md)에 통합했다. 아래의 고정 미루기 횟수 제한, 상태 혼합, 연결 화면 상세 노출 등은 V2에서 수정되었다.

## 이번 버전의 범위

모모 대화 기능은 화면, 홈 버튼, 알림 화면에서 제외한다.

이번 버전은 다음 네 가지 경험만 완성한다.

1. 내 아이에게 맞는 정보를 빠짐없이 수집한다.
2. 엄마가 원문을 읽지 않아도 이해할 수 있게 정리한다.
3. 잊지 않도록 적절한 시점에 반복해서 챙긴다.
4. 준비하거나 처리한 일은 체크하고 이후 알림에서 제외한다.

핵심 성공 경험은 `여러 앱을 열지 않아도 오늘 챙길 일을 알 수 있고, 끝낸 일은 바로 체크할 수 있다`이다.

## 1. 내 아이를 위한 정보 수집

### 수집 출처

- 연결한 교육 앱의 알림
- 학교 공식 홈페이지의 공지와 학사일정
- 나이스 공개 학교정보
- 사용자가 직접 연결한 개인 공지 서비스
- 이미 설치된 교육 앱

앱과 웹이 같은 서비스를 제공하면 앱만 표시하고 앱을 우선 사용한다. 학교 홈페이지나 나이스처럼 역할이 다른 웹 출처는 유지한다.

### 자녀 적합성 판정

모든 수집 자료에 다음 자녀 프로필을 적용한다.

- 자녀 이름
- 학교 정식 명칭과 학교 코드
- 학교급
- 학년
- 반은 사용자가 입력했거나 공식 정보에서 확인된 경우만 사용

공지의 대상이 `초등 5~6학년`이고 자녀가 2학년이면 일반 피드에도 불필요하게 노출하지 않는다. 대상 판단이 불가능하면 `율이에게 해당하는지 확인이 필요해요`로 분류한다.

### 수집 상태

엄마에게는 내부 기술 상태 대신 다음만 보여준다.

- `방금 확인했어요`
- `오늘 오전 9:10에 확인했어요`
- `다시 로그인이 필요해요`
- `일부 소식을 확인하지 못했어요`

각 오류 상태에는 `다시 확인`, `로그인하기`처럼 해결 버튼을 하나 제공한다.

### 중복과 정정 처리

- 같은 공지가 앱 알림과 학교 홈페이지에서 동시에 발견되면 하나로 합친다.
- 제목, 출처, 게시 시각, 본문 특징값으로 동일 공지를 판정한다.
- 수정 공지가 들어오면 기존 카드에 `내용이 바뀌었어요`를 표시한다.
- 기한이나 준비물이 바뀌면 연결된 할 일도 갱신한다.
- 이전 값으로 만든 미완료 알림은 중단하고 변경 내용을 다시 알려준다.

### 수집 검증 화면

연결 화면마다 다음 정보를 제공한다.

- 연결 여부
- 마지막 정상 확인 시각
- 마지막으로 가져온 소식 제목
- 최근 7일간 가져온 건수
- 실패 시 복구 버튼

`연결됨`만 표시해서는 실제 수집 여부를 검증할 수 없다.

## 2. 수집된 정보 제공 방식

### 홈: 오늘의 브리핑

홈은 공지 피드가 아니라 행동 목록이어야 한다.

화면 순서:

1. `오늘 꼭 할 일`
2. `내일 준비할 일`
3. `이번 주 안에 할 일`
4. `참고할 새 소식`
5. 마지막 수집 시각과 연결 이상 상태

각 항목에는 다음 정보만 표시한다.

- 자녀 이름
- 해야 할 행동
- 기한
- 출처
- 체크박스

예시:

```text
□ 율이 체험학습 동의서 제출
  내일 오전 9시까지 · e알리미
```

홈의 `챙길 일 N개`는 화면과 전체 할 일 목록의 미완료 항목 수와 항상 같아야 한다.

### 소식 상세

원문보다 모모의 정리를 먼저 보여준다.

```text
율이는 내일까지 체험학습 동의서를 제출해야 해요.

해야 할 일  동의서 작성 후 제출
기한        9월 20일 오전 9시
준비물      도시락, 물통, 모자
출처        e알리미 · 분당정자초등학교
```

하단 행동:

- `할 일에 추가` 또는 이미 추가된 경우 `챙기는 중`
- `캘린더에 추가`
- `원문 보기`

공지 원문과 판단 근거는 접힌 영역에 둔다. 기술 문구인 `근거 확인`, `원문 날짜 표현`, `수집 내용`, `후보`는 표시하지 않는다.

### 모아본 소식

기존 `받은 알림`을 `모아본 소식`으로 변경한다.

분류 탭:

- 전체
- 해야 할 일
- 일정
- 참고 소식
- 완료

출처 앱별 필터는 보조 필터로 제공한다. 탭에는 패키지명이나 잘린 내부 명칭을 표시하지 않는다.

## 3. 잊지 않게 챙기는 알림

### 알림 종류

#### 즉시 알림

다음 상황만 즉시 알린다.

- 오늘 마감
- 등교·출결 이상
- 기존 일정의 취소 또는 시간 변경
- 로그인이 풀려 수집이 중단됨

#### 묶음 브리핑

일반 공지는 건별로 울리지 않는다.

- 아침: 오늘 해야 할 일과 준비물
- 저녁: 내일 준비할 일
- 주 1회: 다음 주 주요 일정과 신청 마감

사용자가 브리핑 시간을 변경할 수 있게 한다.

### 반복 알림 규칙

할 일마다 긴급도를 계산한다.

- 제출·신청: 전날 저녁, 당일 아침, 마감 1시간 전
- 준비물: 전날 저녁, 등교 전
- 일정: 전날, 시작 1시간 전
- 납부: 3일 전, 전날

완료 체크가 되면 이후 알림은 모두 취소한다.

사용자가 `나중에`를 누르면 다음 선택지를 제공한다.

- 30분 뒤
- 오늘 저녁
- 내일 아침

무한 반복을 막기 위해 같은 일의 미루기는 기본 3회까지 허용하고 이후에는 브리핑에만 포함한다.

### 전체 화면 알림

전체 화면 알림은 긴급한 일과 사용자가 지정한 알람형 할 일에만 사용한다. 일반 공지까지 전체 화면으로 띄우면 피로도가 높아진다.

화면에는 다음만 표시한다.

- 무엇을 해야 하는지
- 누구의 일인지
- 언제까지인지
- `챙겼어요`
- `나중에 다시`
- `자세히 보기`

`소리 끄기`는 보조 기능이며, 일을 완료한 것으로 처리하지 않는다.

## 4. Todo 체크와 상태 관리

### 할 일 상태

모든 할 일은 다음 상태 중 하나를 갖는다.

- `해야 함`
- `진행 중`
- `완료`
- `나중에`
- `취소됨`
- `정보 변경됨`

화면에서는 엄마에게 필요한 `해야 함`, `완료`, `나중에`만 주로 노출한다.

### 체크 동작

체크박스를 누르면 즉시 완료 처리하고 5초간 `되돌리기`를 제공한다.

완료하면 동시에 다음이 갱신되어야 한다.

- 홈의 남은 개수
- 전체 할 일 목록
- 브리핑
- 위젯
- 예약된 반복 알림
- 해당 공지 상세의 상태

한 화면만 바뀌고 다른 화면의 숫자가 남아 있으면 안 된다.

### 부분 체크

하나의 공지에 여러 준비물이 있으면 묶음 전체와 개별 항목을 모두 지원한다.

```text
체험학습 준비물 2/4
☑ 도시락
☑ 물통
□ 모자
□ 돗자리
```

모든 하위 항목을 체크하면 부모 할 일도 자동 완료된다. 부모 할 일을 완료하면 모든 하위 항목도 완료된다.

### 자동 생성과 사용자 제어

- 대상과 행동, 기한이 명확하면 자동으로 할 일을 만든다.
- 선택 활동이나 대상이 불명확하면 할 일을 자동 생성하지 않고 참고 소식으로 둔다.
- 자동 생성된 할 일에는 `모모가 공지에서 추가했어요`를 짧게 표시한다.
- 사용자가 삭제하거나 제외한 공지를 같은 원문에서 다시 만들지 않는다.

## 핵심 데이터 구조

수집된 공지와 할 일을 분리한다.

### Notice

- 출처
- 원문 식별자
- 제목과 본문
- 게시·수집·수정 시각
- 대상 학년과 자녀 적합성
- 추출된 날짜, 준비물, 장소, 비용
- 원문 열기 정보

### Todo

- 연결된 Notice 식별자
- 자녀 식별자
- 행동 제목
- 기한
- 하위 체크리스트
- 상태
- 다음 알림 시각
- 미룬 횟수
- 완료 시각
- 사용자가 직접 만든 항목인지 자동 생성인지

홈, 브리핑, 위젯은 각자 개수를 계산하지 않고 동일한 Todo projection을 사용한다.

## 완료 검수 기준

- 연결한 출처마다 마지막 수집 성공 여부를 확인할 수 있다.
- 자녀 학년과 맞지 않는 공지가 할 일로 생성되지 않는다.
- 같은 공지가 여러 출처에서 와도 Todo는 하나만 생성된다.
- 공지가 수정되면 Todo와 알림도 함께 수정된다.
- 홈 숫자, Todo 목록, 위젯, 브리핑의 미완료 개수가 항상 같다.
- 완료 체크 후 예약 알림이 다시 울리지 않는다.
- 앱을 종료하거나 휴대폰을 재부팅해도 Todo 상태와 알림 예약이 유지된다.
- 엄마가 상세 화면을 연 뒤 5초 안에 해야 할 일과 기한을 찾을 수 있다.
- 큰 글자 150%에서도 체크박스, 기한, 주요 버튼이 잘리지 않는다.
- 오프라인, 권한 거부, 로그인 만료 상태마다 복구 버튼이 있다.

## 실제 사용자 검증

엄마 5명에게 설명 없이 다음 과업을 요청한다.

1. 오늘 해야 할 일을 찾는다.
2. 내일 준비물을 확인한다.
3. 준비한 물건 두 개를 체크한다.
4. 할 일을 완료한다.
5. 완료를 실수로 눌렀다가 되돌린다.
6. 수집이 멈춘 출처를 찾아 다시 연결한다.

각 과업의 성공률, 소요 시간, 탭 수, 잘못 이해한 문구를 기록한다. 핵심 과업 성공률 90% 미만이면 출시하지 않는다.
