# 나는 엄마다 0.6 제품 상태

## 지금 작동하는 에이전트

- 설치된 지원 앱을 찾고 없는 앱을 추천한다.
- 선택한 앱의 새 알림을 기기 안에 암호화한다.
- 준비물·제출·신청·회신·마감·납부 후보를 찾는다.
- 상대 날짜와 숫자 날짜를 절대 날짜 후보로 바꾸고 엄마에게 확인받는다.
- 엄마가 정한 시각에 private 부탁 알림을 보낸다.
- 최근 알림, 챙길 후보, 미완료 부탁 질문에 기기 안의 근거로 답한다.
- 실행 명령은 확인 후 부탁으로 저장한다.
- 후보 감지·종류·기한을 검토 자료에 자동 포함해 연구자가 원문과 대조할 수 있다.

## 공식 개인 공지 연결 판단

e알리미와 하이클래스 보호자 개인 공지를 읽는 공개 개발자 API는 확인되지 않았다. 현재 웹 연결은 사용자가 공식 HTTPS 화면에서 로그인하고 완료로 표시한 상태와 쿠키 소실만 관리한다. 로그인 성공·서버 세션·새 공지 조회를 증명하지 않으며 앱에도 그렇게 표시한다.

공급자별 정식 커넥터에는 다음 계약이 필요하다.

1. 공식 OAuth 또는 위임 토큰
2. 로그인 상태 검증 endpoint
3. 공지 목록·본문·첨부파일 API
4. 세션 만료·철회 callback
5. 호출 한도·보관·재배포 약관

이 계약 없이 비밀번호 자동 입력, 접근성 자동조작, 앱 화면 크롤링을 제품 기능으로 넣으면 계정 보안과 서비스 변경에 취약해진다.

## 실사용 검증

0.6은 엄마에게 평가 행동을 요구하지 않는다. 7~14일 뒤 사용자가 명시적으로 검토해 내보낸 후보 결과를 연구자가 원문 공지와 대조해 다음을 계산한다.

- 후보 정밀도: 원문상 실제 행동 필요 후보 / 전체 자동 후보
- 오탐률: 원문상 행동 불필요 후보 / 전체 자동 후보
- 누락률: 자동 후보가 아니지만 원문상 행동이 필요한 공지 / 실제 행동 필요 공지
- 앱별 본문 확보율과 기한 해석 성공률

목표 표본은 엄마5~10명, 알림300건 이상이다. 엄마는 앱을 평소처럼 사용하고, 검증 작업은 제품팀이 수행한다. 이 데이터가 쌓이기 전에는 실제 공지 정확도가 검증 완료됐다고 선언하지 않는다.
