# 나는 엄마다 — 에이전트 알림과 실행 UX

후속 요구 반영: 사용자가 시간을 정한 ‘비서 알람’과 듣는 브리핑을 선택할 수 있도록 [11 최종 점검](11-최종점검-비서알람-연결유지.md)에 옵션·화면·예외·검증 기준을 추가했다. 일반 공지는 기존 묶음 알림을 유지하며 지정 알람은 별도 OS 권한·배포 요건 검증 대상이다. 둘 다 현재 Task/Reminder 구현 완료를 뜻하지 않는다.

2026-09-13 · 제품 기준 / Task 엔진 구현 전 설계

## 판단

일반 공지·준비물마다 앱 전체 화면을 강제로 띄우지 않는다. Android14 이상에서 전체화면 Intent는 전화·알람 같은 극히 높은 우선순위 용도로 제한되고 Play 심사 대상이다. 엄마 비서는 **heads-up 중요 알림 + 처리 전 유지 + 알림 안의 실행 버튼 + 아침/저녁 브리핑**을 기본으로 한다.

근거: [Android14 전체화면 알림 제한](https://developer.android.com/about/versions/14/behavior-changes-14), [Google Play 전체화면 Intent 요건](https://support.google.com/googleplay/android-developer/answer/16965181?hl=en).

## 알림 레벨

| 레벨 | 예시 | 표시 | 반복 |
|---|---|---|---|
| 즉시 확인 | 오늘 일정 취소·시간 변경·당일 마감 | 잠금화면/상단 heads-up, 소리·진동은 사용자가 선택 | 최초1회. 미확인 상태는 앱 홈에 유지 |
| 오늘 행동 | 오늘 제출·내일 준비물·배송 마감 | 다음 아침/저녁 브리핑과 필요 시 일반 알림 | 같은 슬롯에 묶음 |
| 참고 | 학교에서 제공하는 물품·급식·일반 공지 | 푸시 없음, 앱 브리핑/기억에만 표시 | 없음 |
| 사용자 지정 | 엄마가 ‘이 시간에 꼭’ 선택한 항목 | 지정 시각 일반 중요 알림 | 지정1회 |

생명·의료·안전 긴급 서비스를 표방하지 않는다. ‘놓치면 안 됨’이라는 이유만으로 모든 알림을 긴급으로 올리지 않는다.

## 하루 리듬

- 아침 브리핑 기본 07:00: 오늘 일정·준비물·마감, 바로 처리 가능한 버튼.
- 낮: 새 변경·당일 임박만 알림. 새로운 정보가 없으면 조용히 유지.
- 저녁 브리핑 기본 20:30: 내일 준비·아직 안 한 일·배송/구매 필요.
- 사용자가 시간과 소리/진동을 바꿀 수 있다. 초기에는 복잡한 규칙 편집기를 만들지 않는다.

## 알림 문장

에이전트가 결론부터 말한다.

```text
모모 · 내일 준비할 것 2개
미술 준비물과 체험학습 동의서가 있어요.

[준비물 보기]  [30분 뒤]  [완료]
```

```text
모모 · 일정이 바뀌었어요
목요일 수학 수업은 쉬고, 토요일 11시에 보강해요.

[변경 확인]  [나중에]
```

```text
모모 · 구매 후보를 찾았어요
8절 스케치북, 수요일 도착 가능한 후보 2개예요.

[가격 비교]  [이미 샀어요]  [나중에]
```

잠금화면에서는 기본적으로 아이 이름·학교·물품을 숨기고 ‘챙길 일이 있어요’만 표시한다. 사용자가 상세 표시를 켤 수 있다.

## 알림에서 바로 처리

- 완료/이미 샀어요: 상태 저장 후 관련 알림 취소. 버튼 재클릭은 멱등.
- 미루기: 마감은 바꾸지 않고 다음 알림 시각만 변경.
- 준비물 보기: 우리 앱의 해당 카드로 직접 이동.
- 가격 비교: 동일 규격·수량·배송 조건의 후보 화면으로 이동.
- 구매 링크: 사용자가 선택한 판매처를 열며, 자동 주문·결제하지 않는다.
- 제출/서명: 원 서비스가 필요한 경우 해당 문서로 이동한다. 제출 완료를 자동 추정하지 않는다.

## 까먹지 않게 하는 방법

알림을 ‘봤다’와 ‘처리했다’를 구분한다. 알림을 밀어 없애도 미완료 일은 홈의 ‘제가 챙기고 있어요’에 남는다. 다음 브리핑에는 아직 유효한 미완료 일만 다시 포함한다.

같은 일을 계속 울려 피로하게 만들지 않는다. D-1/당일 반복, 사용자가 미룬 알림, 일정 변경을 하나의 Action 버전으로 관리한다. 완료·취소·삭제·원문 변경 시 과거 예약을 모두 무효화한다.

## 홈 화면 우선순위

1. 에이전트 한 문장: 오늘 가장 중요한 일.
2. 즉시 할 수 있는 주 버튼: 준비/비교/완료/변경 확인.
3. 오늘 챙길 것.
4. 다음 일정·참고.
5. 연결 문제는 작고 명확한 한 줄 배너.

받은 알림 수·연결 수 같은 시스템 통계는 홈의 중심이 아니다. 연결 상태와 기술 설명은 설정으로 보낸다.

## 구현 게이트

현재 v0.2는 알림 원문 수집과 나이스 공개 일정 연결까지다. 위 실행 버튼을 실제 알림에 넣기 전에 Action 모델·중복·완료·미루기·변경 감지·리마인더 엔진을 구현하고 AC18/AC19/AC26을 실기기에서 검증한다.

전체화면 알림 권한은 현재 Manifest에 추가하지 않는다. 사용자 지정 알람이 제품의 핵심 기능으로 검증되고 Play 요건을 충족하는 경우에만 별도 검토한다.
