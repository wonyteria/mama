# 최종 점검: 엄마 비서, 알림 설정, 연결 유지

2026-09-13 · 코드 검수와 후속 구현 기준. 이 문서는 09/10 문서와 충돌하는 알림·세션 관련 제안을 대체한다. 이번 작업은 검수와 설계 정리이며 APK를 수정하거나 새 기능을 설치한 기록이 아니다.

## 제품의 합격 기준

엄마가 최초 연결과 필요한 재인증을 마치면, 지원 정보원을 매번 직접 열지 않아도 필요한 준비·마감·변경을 우리 앱에서 확인하고 처리한다. 지원하지 않거나 확인에 실패한 정보원은 확인했다고 표시하지 않는다. 목표는 무조건 로그인 영구 유지가 아니라, 엄마가 직접 확인해야 하는 횟수와 놓친 일을 줄이는 것이다.

## 설정 화면 결정

- ‘연결 상태 자세히 보기’: 기본 설정에서 제거하고 ‘도움말 → 연결 문제 해결’ 안으로 이동한다. 연결 문제 발생 시 해당 사이트 행과 홈에 복구 행동 하나를 노출한다.
- ‘수집·보관·삭제 설명’: 기능은 유지하고 이름을 ‘개인정보 및 데이터’로 바꾼다. 보관·내보내기·전체 삭제를 이곳에 모은다. 최초 연결 시 필요한 설명만 맥락에 맞게 보여준다.
- 기본 설정 목록: 자녀 / 연결한 앱·사이트 / 비서 알림 / 개인정보 및 데이터 / 도움말.
- 알림 수집 접근과 우리 앱 알림 발송은 별개다. 웹만 쓰는 엄마에게 알림 읽기 권한을 요구하지 않는다. 비서 알람 사용 시 발송·정확한 알람·전체화면 권한은 각각 필요한 시점에만 요청한다.

## 비서 알림 옵션

| 옵션 | 기본 제안 | 동작 |
|---|---|---|
| 아침 브리핑 | 07:00, 처음 저장 시 사용자 확인 | 오늘 일정·준비·마감, ON/OFF와 시간 선택 |
| 저녁 브리핑 | 20:30, 처음 저장 시 사용자 확인 | 내일 준비와 미완료, ON/OFF와 시간 선택 |
| 요일 | 매일, 평일/요일 지정 가능 | 제외한 요일에는 정기 브리핑 없음 |
| 일정 미리 알림 | 30분 전 | 일정 시작시각이 있을 때만, 끄기/10분/30분/1시간 |
| 준비·마감 | 전날 저녁, 당일 아침 | 브리핑에 병합, 준비 완료·취소는 제외 |
| 변경 즉시 알림 | ON | 취소·시간 변경·당일 마감만 묶음 중복 없이 알림 |
| 알리는 방식 | 일반 알림 / 비서 알람 | 비서 알람은 사용자가 명시 선택한 시간·항목에 한정 |
| 소리·진동 | 사용자 선택 | OS 음량·방해금지 상태를 존중 |
| 음성 읽기 | 듣기 누르면 재생 | 잠금화면에서 개인정보 자동 발화 없음 |
| 조용한 시간 | 21:00~07:00 | 일반 변경 알림 보류. 지정 비서 알람의 예외는 별도로 선택 |
| 미응답 재알림 | 기본 OFF | 선택 시 10분 뒤 1회, 무한 반복 금지 |

저장은 하나의 트랜잭션으로 처리한다. 저장 성공 후 기존 예약 취소·새 버전 예약. 실패 시 이전 설정 유지, 이중 발송 금지. 동일 시각의 브리핑·마감·일정은 묶어 한 번만 울린다. 처리할 일이 없으면 기본적으로 브리핑도 생략한다.

## 전화하듯 알려주는 비서 알람

실제 전화번호를 사용하는 통화가 아닌 앱 내부 일정 알람이다. ‘모모의 아침 브리핑’처럼 정체성을 표시한다. 전화 기능을 가장해 시스템 통화 권한을 얻지 않는다.

```text
설정 → 비서 알림
  아침 [ON] [07:00]   저녁 [ON] [20:30]
  요일 [매일 ▼]      일정 [30분 전 ▼]
  방식 [일반 알림 / 비서 알람]
  [소리·진동·조용한 시간 >]
  [미리 듣기] [저장]

지정 시각 → 모모가 챙길 일이 있어요
  [듣기] [10분 뒤] [지금은 닫기]

듣기 → 필요시 잠금 해제 → ‘오늘 준비할 것은 두 가지예요’
  [준비물 보기] [구매 후보] [준비 완료]
```

알람은 최대 30초 소리·진동 후 멈춘다. 닫기·미응답은 완료가 아니며 할 일은 홈에 남는다. 듣기도 완료로 처리하지 않는다. 실제 통화 중에는 음성을 중지하고 이후 확인할 카드로 유지한다. 음성 엔진·언어 팩이 없으면 텍스트 브리핑으로 대체한다. 구매 후보가 없으면 비활성 가짜 버튼 대신 필요한 물품만 표시한다. 상품 링크 열기로 구매 완료를 추정하지 않는다.

전체화면은 Android/배포 요건과 사용자 권한을 충족한 일정 알람에서만 시도한다. 화면 잠금/사용 중에 따라 OS가 상단 알림으로 표시할 수 있다. 정확한 알람 접근이 없으면 ‘정확한 시각 보장 불가’를 설정에 표시하고 일반 알림으로 대체한다. 강제 종료·전원 OFF·제조사 절전 상황까지 항상 울린다고 약속하지 않는다.

참고: [Android 전체화면 변경](https://developer.android.com/about/versions/14/behavior-changes-14), [Play 전체화면 요건](https://support.google.com/googleplay/android-developer/answer/13392821?hl=en), [정확한 알람](https://developer.android.com/develop/background-work/services/alarms).

## 로그인 유지의 실제 처리 계약

쿠키 디스크 저장은 서버의 세션 유효기간 연장이 아니다. 일부 사이트는 활동에 따라 유휴 만료가 연장되지만, 절대 만료·비밀번호 변경·강제 로그아웃·추가 인증은 방문을 반복해도 해소되지 않는다. 사이트별 규칙을 실제로 확인해야 한다.

1. 공식 API/토큰 갱신이 있으면 만료 정보에 따라 제공자가 지원하는 갱신을 한다. 서버에서 받은 새 토큰을 원자적으로 저장하며 동시 갱신은 하나로 합친다.
2. 웹 세션 방식은 서비스별 허용된 읽기 요청과 인증 확인 어댑터를 구현한다. 단순 첫 화면 방문이나 login 문자열 부재로 인증 성공을 판단하지 않는다.
3. 정보 확인 요청 시 세션 상태를 함께 검사한다. 지원되는 자동 로그인/갱신 경로가 있으면 재사용한다. 의미 없는 잦은 새로고침을 공통 해법으로 삼지 않는다.
4. 알려진 갱신 가능 만료시각 이전에 작업을 예약하되, 절전·네트워크 지연에 대비해 실행 직전 재검사한다. 만료시각이 없으면 임의 추측해 보장하지 않는다.
5. 인증 만료는 REAUTH_REQUIRED, 네트워크 장애는 ERROR, 아직 로그인 검증 전은 UNVERIFIED로 구분한다. HTTP 403은 인증 만료라고 단정하지 않는다.
6. 재인증 불가 시 ‘e알리미 확인이 멈췄어요. 한 번 로그인해주세요’와 직접 진입 버튼을 보여준다. 같은 장애를 매번 울리지 않는다. 다른 정보원은 계속 확인한다.
7. 마지막 성공 시각 이후를 기준으로 새 공지·수정·첨부를 증분 조회한다. 완료한 항목을 재생성하지 않는다. 재로그인 후 놓친 기간을 복구하고 복구 불가 범위를 알린다.
8. OFF·전체 삭제는 예약/진행 작업을 무효화하고 쿠키·DOM 저장소·관련 캐시·연결 메타데이터를 지운다. 제공자가 폐기 API를 제공하면 요청한다. 로컬 삭제와 서버 로그아웃 성공을 구분한다.

참고: [CookieManager flush](https://developer.android.com/reference/android/webkit/CookieManager)는 쿠키 저장 API다. [OWASP 세션 관리](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)는 유휴 만료와 활동과 무관한 절대 만료를 구분한다.

이전 테스트 21개 통과와 APK 설치 성공은 위 기능을 증명하지 않는다. 테스트 이름만으로 실제 로그인·자동 수집·정시 알람이 검증됐다고 해석하지 않는다. 현재 상태는 연결 진입 프로토타입이며 실사용 비서 완성 판정은 보류한다.

## 다음 구현의 필수 검증

- 로그인하지 않은 공개 홈에서 성공 표시 금지. 로그인 취소·오류·프로세스 종료도 복구.
- 정상 세션, 유휴 만료, 절대 만료, 강제 로그아웃, 비밀번호 변경, OTP 재요구를 각각 시험.
- 앱 닫힘/잠금/절전/재부팅/오프라인 뒤 복귀에서 신규·수정·첨부 누락과 중복 확인.
- 웹 OFF·전체 삭제 후 자동 재로그인/잔존 세션/늦은 응답 저장 없음.
- 알람 시간 변경·요일·조용한 시간·중복 시각·권한 철회·통화 중·글꼴 확대 검증.
- 소리 중지·듣기·완료·미루기 구분. 완료/삭제 뒤 예전 알람이 울리지 않음.
- 원 공지와 비교한 자동 포착률·필수정보 정확도·재로그인 빈도·배터리 소모를 7일 이상 관찰. 계정 보유자가 로그인하며 비밀번호를 대화나 로그에 남기지 않음.
