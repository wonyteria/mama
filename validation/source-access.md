# 교육 원천 접근 검토

조사일: 2026-09-13 KST. 공개된 공급자·교육 공공기관 자료를 읽었다. 로그인, 내부 API 추정/호출, 역공학, 실제 보호자 데이터 수집, 공급자 연락을 하지 않았다. 페이지 게시일이 표시되지 않은 것은 조사일만 기록한다.

## 판정

**공개 자료만으로 학교종이·e알리미의 개인 공지 전체를 무입력으로 지속 확보할 수 있다고 입증하지 못했다.** 조사한 공식 소개·도움말·앱 등록정보에서 제3자가 보호자 개인 공지 원문을 읽는 공개 개발자 API/OAuth 문서는 찾지 못했다. API가 존재하지 않는다는 뜻은 아니다.

보조 자동 입력 후보는 확인했다. NEIS 공식 학사일정 API는 학교 공개 행사 정보를 제공한다. 학교 홈페이지 공개 게시판에도 일부 원문이 존재하며 두 공급자는 이를 자기 서비스로 가져오는 기능을 설명한다. 다만 **공공 일정과 공개 공지는 개인별 동의서·준비물·회신/납부 완료·비공개 변경 정보를 대신하지 못한다.**

더 중요한 새 근거가 있다. 학교종이는 **대상 변경이나 글 삭제 후 알림이 남을 수 있다**고 설명한다. 그러므로 NLS에 남아 있는 알림을 현재 유효한 업무·현재 열람 권한의 증거로 취급하면 안 된다. 초기 알림을 잘 읽는 것만으로 최신 상태 유지까지 입증되는 것은 아니다. [학교종이: 새글 알림은 왔지만 글이 보이지 않는 경우](https://schoolbell-e.oopy.io/post_visibility_issue)

## 이번 검색으로 남은 미확인 사항

- 두 앱의 실제 Android 시스템 알림 title/text/bigText 예시나 payload 명세에서 날짜·행동·아이 필드가 충분함을 입증할 자료를 확보하지 못했다. 제목만 온다고 단정하는 것도 근거가 부족하다.
- 알림에 본문이 충분한 비율과 업무 원문 자체가 알림을 생성하는 비율은 측정하지 않았다.
- 원문 취소·수정·발행대상 제외가 어떤 알림 이벤트로 반영되는지, 알림이 유지되는 경우 이를 자동 탐지할 공식 경로가 있는지 확인되지 않았다.
- 공급자 변경 계획/버전 업데이트 후 호환성, 학교 관리자별 설정 차이, 아이별 문서 식별자 유지, 첨부 처리, 다자녀 대상 분리가 미검증이다.
- e알리미와 학교종이의 공개 원문 API/OAuth/webhook은 조사한 자료에서 미발견이다. 비공개 제휴 API 가능성을 부정하지 않는다.

조사 범위: 공급자 공식 홈페이지·Play 등록정보·학교종이 역할별 도움말과 푸시/연동/열람 FAQ·e알리미 기능 소개 및 상담 경로·NEIS 개발자/학사일정 문서·공개 학교 안내. 검색어는 공급자명과 API/연동/푸시/알림/매뉴얼/이메일 조합 및 공식 도메인 제한 검색을 사용했다. 비공식 블로그 설명은 payload나 기능 확정 근거에서 제외했다.

## 사업 의사결정에 반영할 내용

현재 “교육 공지를 모두 자동으로 챙긴다”는 판매 약속을 할 근거는 없다. **공개 일정은 자동화 가능 후보, 개인 공지 수집과 변경 추적은 별도 검증이 필요한 핵심 위험**으로 분리한다. 공공 일정을 붙였다는 이유로 원래의 준비물·제출·납부 비서 가설이 검증된 것으로 처리하지 않는다.

입력 실험에는 기존 필드 충분성 외에 **원문 변경·삭제·대상 제외 후 비서가 낡은 업무를 계속 안내하는지**를 추가해야 한다. 실제 원문 변화가 NLS에 관측되지 않는다면, 공식 연동/제휴 없이는 그 업무의 최신성을 보장하는 약속을 줄여야 한다.
